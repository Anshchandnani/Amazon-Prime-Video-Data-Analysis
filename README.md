# Amazon Prime Video Dashboard | Power BI

## 📊 Project Overview

This project is a data visualization dashboard built using **Microsoft Power BI** to explore the Amazon Prime Video titles dataset.

The dashboard presents information about movies and TV shows through interactive visualizations, making it easier to explore content categories, ratings, genres, directors, and release-year trends.

This project was developed as part of my learning journey in **Data Analytics and Business Intelligence**.

## 🎯 Project Objectives

- Explore and visualize the Amazon Prime Video titles dataset.
- Understand the distribution of movies and TV shows.
- Examine content ratings and genre classifications.
- Explore release-year trends.
- Practice creating clear and informative Power BI reports.

## 🛠️ Tools and Technologies

- **Microsoft Power BI** — dashboard development and data visualization
- **CSV** — source dataset format
- **Data Visualization** — charts, KPI cards, and report layout

## 📈 Dashboard Features

The dashboard explores the dataset using visual elements such as:

- **KPI Cards:** Display key summary information.
- **Bar Charts:** Compare content categories and other selected attributes.
- **Donut Chart:** Visualize the distribution of content types.
- **Area Chart:** Explore content trends across release years.
- **Dashboard Layout:** Organize visualizations into a structured report.

*Note: The features listed above describe the intended report content. Refer to the included Power BI file for the visuals actually implemented.*

## 🚀 How to Open the Project

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Dashboard_Ansh.pbix`.
4. If prompted, update the CSV file path to the location of `amazon_prime_titles.csv`.
5. Refresh the data if required.
6. Explore the report and its visualizations.
